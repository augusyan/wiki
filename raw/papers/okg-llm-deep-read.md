## 2. 一句话总结

本文提出 **OKG-LLM**，首次系统构建面向全球海表温度预测的 **Ocean Knowledge Graph, OKG**，并通过知识图谱编码、区域级检索、跨注意力细粒度对齐和冻结 LLM 表征学习，将海洋领域知识与数值 SST 时间序列融合，从而显著优于传统时序模型和 LLM 时序预测模型。

## 3. 研究背景

海表温度，即 **Sea Surface Temperature, SST**，是影响全球气候变化的重要变量，也广泛服务于天气预报、风暴追踪、渔业管理等任务。论文指出，SST 预测已经成为海洋科学与计算机科学交叉的重要问题。

传统上，SST 预测可以看作一个时空时间序列预测问题。已有方法主要分为两类：一类是基于物理规律的数值模式，例如 ECMWF 系统；另一类是数据驱动方法，例如 CNN、RNN、Transformer、Informer、FEDformer、DLinear、FreTS 等。数据驱动方法在历史 SST 序列中学习时间依赖和空间相关性，取得了较好效果，但它们往往只依赖观测数据本身，很少显式利用海洋科学长期积累的先验知识。

论文认为，这种忽略领域知识的做法限制了 SST 预测模型的进一步提升。原因在于，海洋中的很多现象与 SST 变化高度相关，例如洋流、季风、气候带、ENSO 区域、上升流区域等。比如秘鲁寒流与东太平洋冷舌区域的 SST 变化密切相关，这类知识很难仅从数值序列中稳定学习出来。

## 4. 研究动机

本文动机可以概括为两个核心挑战。

第一，**已有模型难以充分表示海洋知识和区域间复杂相关性**。许多 LLM 时间序列方法会使用简单文本提示，例如“预测每周收集的全球海表温度”，但这种粗粒度提示无法表达不同海域背后的洋流、季风、海盆、气候区域等丰富知识。另一方面，传统 SST 模型常用距离或数据相关性来建图，容易忽略由洋流、气候遥相关、季风等物理机制形成的高阶区域关系。

第二，**海洋知识与数值 SST 数据之间存在模态和粒度差异**。海洋知识通常是宏观、符号化、定性的，例如“某区域受某洋流影响”；而 SST 观测数据是微观、定量、细粒度的时间序列。如何把宏观知识映射到 1,715 个细粒度海洋网格区域，并与各区域的 SST 序列对齐，是本文要解决的关键问题。

因此，作者希望构建一种框架，使 LLM 不只是作为通用特征提取器，而是能在结构化海洋知识增强下，对不同区域的 SST 动态进行更准确建模。

## 5. 相关工作总结

### 5.1 海表温度预测

论文将 SST 预测方法分为数值模式和数据驱动模式。数值模式基于物理方程和海洋动力学原理，具有可解释性，但计算成本高，且依赖较强假设。数据驱动方法则利用历史数据学习复杂依赖关系，近年来 RNN、Transformer、Informer、FEDformer、TimeXer、DLinear、FreTS 等都被用于时序预测。

这些方法的问题在于，大多数只关注数值序列中的统计模式，而没有系统融入海洋领域知识。因此，模型可能难以理解不同区域之间由洋流、季风、海盆结构等因素导致的物理联系。

### 5.2 LLM 用于时间序列预测

随着 GPT、Llama、DeepSeek 等大语言模型的发展，LLM 被逐渐引入时间序列预测。代表性方法包括 GPT4TS、PromptCast、OFA、UniTime、TimeLLM 等。这些方法通常把时间序列转换为 token 或 patch，再利用 LLM 的序列建模能力进行预测。

论文认为，现有 LLM 时序预测方法仍存在不足：它们多数把 LLM 当作通用特征编码器，而不是充分利用领域知识进行推理。特别是在海洋预测任务中，仅用文本提示很难覆盖复杂的海洋地理、物理和气候机制。

### 5.3 领域知识增强预测与知识图谱

知识图谱可以结构化表示实体及其关系，已在城市计算、生物科学、地学、材料科学等领域中用于增强预测或推理。近年来也出现 GraphRAG、KG2RAG 等利用知识图谱增强 LLM 检索和推理的方法。

但论文指出，现有 KG + LLM 方法主要面向文本任务，而如何将知识图谱与细粒度数值时间序列结合仍然研究不足。本文的核心贡献正是在这一缺口上提出一种面向 SST 预测的知识—数据细粒度对齐框架。

## 6. 方法详细总结

本文提出的模型称为 **OKG-LLM**，整体由四个主要模块组成：时间序列编码模块、海洋知识图谱编码模块、LLM 驱动的细粒度对齐模块、预测输出模块。论文第 5 页的框架图展示了完整流程：左侧输入 SST 数值数据与外部 OKG，中间分别经过时序编码和知识图谱编码，随后通过区域级检索与跨注意力对齐进入冻结 LLM，最后由 Transformer Decoder 和线性层输出预测。

### 6.1 问题定义

作者将历史 SST 数据表示为矩阵：

[
X \in R^{N \times T}
]

其中 (N) 是海洋区域数量，(T) 是历史时间步数量。每个区域 (i) 的 SST 序列为：

[
X_i = (x_{i,1}, x_{i,2}, ..., x_{i,T})
]

目标是预测未来 (\tau) 个时间步的 SST：

[
\hat{Y} = F_{\theta}(X)
]

引入海洋知识图谱后，任务变为：

[
\hat{Y} = F_{\theta}(X; OKG)
]

也就是说，模型不仅利用历史观测序列，还利用 OKG 中的结构化海洋知识。

### 6.2 Ocean Knowledge Graph 的构建

本文构建了一个专门用于 SST 预测的 **Ocean Knowledge Graph, OKG**。OKG 包含五类与 SST 变化强相关的实体：

- 海洋区域 Region
- 洋流 Ocean Currents
- 季风 Monsoons
- 大洋 Oceans
- 海区 Sea Areas

关系类型包括：

- `located_in`
- `part_of`
- `influenced_by`
- `adjacent_to`

论文第 4 页的图 1 展示了 OKG 的整体拓扑和局部子图。OKG 总共包含 **1,829 个实体** 和 **4,602 个三元组**。其中最细粒度的实体是 Region，对应预测中的空间网格区域。

为了把宏观海洋知识映射到细粒度区域，作者采用两步方法。首先，从 NOAA 技术报告、海洋图集和经典论文等权威来源中数字化洋流、季风、海域等边界。其次，对每个海洋网格区域取其中心经纬度，通过 point-in-polygon 算法判断该区域是否属于某个海洋现象边界内部。对于重叠区域，例如同时受洋流和季风影响的区域，模型会保留多个关系。

这种做法的优点是可复现、结构清晰，并能够把宏观海洋概念显式连接到具体预测网格。

### 6.3 时间序列编码模块

时间序列编码模块用于把原始 SST 序列转换成时序特征嵌入。作者首先对每个区域的 SST 序列使用 **Reversible Instance Normalization, RevIN**，以缓解时间序列中的分布漂移。随后，将序列切分成 patch，以聚合局部时间特征并降低计算成本。

对于区域 (i)，切分后的 patch 表示为：

[
X_p^{(i)} \in R^{P \times L_p}
]

其中 (L_p) 是 patch 长度，(S) 是步长，patch 数量为：

[
P = \lfloor (T - L_p)/S \rfloor + 1
]

接着，使用 MLP 将 patch 投影到 (d_m) 维嵌入空间：

[
e_{ts}^{(i)} = MLP(X_p^{(i)})
]

最终得到所有区域的时间序列嵌入：

[
E_{ts} \in R^{N \times P \times d_m}
]

这个模块的作用是从局部时间片段中提取 SST 变化模式，为后续与知识图谱嵌入对齐提供基础。

### 6.4 海洋知识图谱编码模块

OKG 编码模块用于把符号化图谱知识转化为连续向量表示。它包含两个并行分支：**预训练实体嵌入** 和 **区域邻居检索语义嵌入**。

#### 6.4.1 基于 TransE 的结构嵌入

作者使用 TransE 对 OKG 进行预训练。对于三元组 ((h, r, t))，TransE 假设：

[
h + r \approx t
]

通过 margin-based ranking loss 学习实体和关系嵌入。预训练后，每个实体都会得到一个结构感知的向量 (e_{struct})。这些嵌入在 SST 模型训练中通常被冻结，以保留图结构知识并降低训练成本。

该分支主要捕获区域间的结构相关性，例如某区域属于哪个海、受哪些洋流影响、与哪些区域相邻。

#### 6.4.2 区域邻居检索语义嵌入

仅有 TransE 结构嵌入可能不足以表达实体的具体语义属性，因此作者设计了区域邻居检索模块。对目标区域实体 (e)，首先检索其 (k)-hop 邻居子图 (N_K(e))，然后把邻域中的三元组线性化为自然语言文本：

[
Text(e) = Concat(D(e); D(h,r,t) | (h,r,t) \in N_K(e))
]

论文第 5 页的图 3 展示了该模块：对于一个区域 (r_1)，模型会把诸如“该区域平均温度为 xx °C”“位于某大洋”“属于某海区”“受某洋流影响”等三元组转写成文本，再送入 LLM 得到 token embedding。

实践中作者使用 1-hop 邻居，以在计算效率和语义完整性之间取得平衡。

#### 6.4.3 Adapter 融合结构与语义知识

最后，作者使用一个轻量级 MLP adapter 融合结构嵌入 (e_{struct}) 和文本语义嵌入 (e_{text})：

[
e_{kg} = Adapter([e_{struct}; e_{text}])
]

由此得到每个区域的知识增强表示：

[
E_{kg} \in R^{N \times l \times d}
]

这个设计使得模型同时拥有图结构关系和局部语义描述。

### 6.5 LLM 驱动的细粒度对齐模块

这是本文最关键的模块，用于解决海洋知识与 SST 数值数据之间的粒度和模态差异。

对于每个区域 (i)，模型先取该区域的实体知识嵌入 (e_{region}^i)，并与其时间序列嵌入 (e_{ts}^i) 拼接，形成查询向量：

[
e_{query}^i = LayerNorm(concat[e_{region}^i, e_{ts}^i])
]

然后通过跨注意力机制，让该区域的时间序列表示去关注知识图谱嵌入 (E_{kg})：

[
E_{aligned} = softmax \left(\frac{(E_{query}W_Q)(E_{kg}W_K)^T}{\sqrt{d_k}}\right)(E_{kg}W_V)
]

这种设计实现了区域级知识检索和对齐。它不是用一个统一 prompt 描述整个数据集，而是针对每个区域检索其相关知识并进行融合，因此更符合海洋区域异质性。

之后，作者将对齐后的嵌入直接输入冻结的预训练 LLM。值得注意的是，模型没有使用 LLM 原生 tokenizer，而是把 aligned embedding 作为 transformer 层输入。LLM 的参数被冻结，主要作为高维表示空间和序列建模器。

### 6.6 预测输出模块

LLM 输出的高维表示会进入一个可训练的 Transformer Decoder。该模块通过多头自注意力进一步建模 SST 的时空依赖：

[
Attention(Q,K,V)=softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V
]

最后通过线性层映射到未来 (\tau) 个时间步的预测值。训练目标使用 L1 loss，即最小化预测值与真实值之间的绝对误差。

## 7. 实验设计

### 7.1 数据集

实验使用 **NOAA Optimum Interpolation Sea Surface Temperature, OISST, version 2.1** 数据集，来源于 NOAA Physical Sciences Laboratory。该数据集提供从 1991 年至今的全球每周 SST 观测数据。空间分辨率为 **5° × 5°**，约包含 1,800 个海洋网格。数据按照时间顺序划分为训练集、验证集和测试集，比例为 **7:1:2**。

### 7.2 预测设置

所有方法都使用过去 (T) 个时间步的 SST 观测值预测未来 (\tau) 个时间步。论文测试了三个预测长度：

- (\tau = 8)
- (\tau = 16)
- (\tau = 32)

这分别对应不同长度的未来周尺度 SST 预测。

### 7.3 对比方法

论文比较了 OKG-LLM 与 10 个基线模型，包括传统时序预测方法、LLM 时序预测方法和物理启发模型：

传统或典型预测模型包括：

- Informer
- FEDformer
- DLinear
- FreTS
- TimeMixer+
- PGAN / PGCN，论文表格中列为 PGCN，正文描述为物理启发图模型

LLM-based 方法包括：

- GPT4TS
- UniTime
- TimeLLM
- TimesFM

这些基线覆盖了 Transformer、线性模型、频域模型、LLM 重编程方法和时间序列基础模型等不同技术路线。

### 7.4 实验环境与指标

所有模型使用 Python 和 PyTorch 1.13.1 实现，在 4 张 NVIDIA 4090 GPU 的服务器上运行。优化器为 Adam，最大训练 50 个 epoch，并采用 early stopping 防止过拟合。学习率初始为 0.0001，每 4 个 epoch 减半。

评价指标为：

- MAE：Mean Absolute Error
- MSE：Mean Squared Error

两者都是时间序列预测中常用指标，数值越低表示预测越准确。

## 8. 结果与分析

### 8.1 主实验结果

论文第 8 页的表 I 给出了不同预测长度下所有模型的 MSE 和 MAE。OKG-LLM 在 (\tau=8,16,32) 三个预测长度下均取得最优表现。尤其当 patch size (P=4) 时效果最好：

- (\tau=8)：MSE = 0.098，MAE = 0.207
- (\tau=16)：MSE = 0.133，MAE = 0.241
- (\tau=32)：MSE = 0.163，MAE = 0.268

相比第二好的 TimeLLM，OKG-LLM 在不同预测长度上的 MSE 提升约为 **7.5% 到 15.1%**。

这说明单纯使用 LLM 进行时序建模已经优于许多传统模型，但进一步引入结构化海洋知识后，可以显著提升预测精度。

### 8.2 长期预测鲁棒性

随着预测长度从 8 增加到 32，大多数基线模型误差明显上升，而 OKG-LLM 仍保持相对稳定的优势。这表明知识图谱中的物理和地理先验有助于模型在更长预测跨度上维持稳定性。

论文还分析了 patch size 的影响。结果显示 (P=4) 最优，作者认为这是因为它在时间分辨率和上下文抽象之间取得了平衡；过小的 patch 容易包含冗余局部模式，过大的 patch 则可能损失细粒度动态信息。

### 8.3 效率分析

论文第 8 页的表 II 比较了 LLM-based 方法的参数量、显存占用和每 batch 处理时间。OKG-LLM 的参数量为 40.15，显存占用为 1,345，速度为 0.21 秒。相比 TimeLLM，OKG-LLM 大幅降低了计算开销，同时显著提高预测精度。

这说明 OKG-LLM 并不是靠更大的模型规模取胜，而是靠知识对齐机制带来性能收益。

### 8.4 消融实验

论文第 9 页的图 4 展示了消融实验。作者移除了三个关键组件：

- 去掉 Time Series MLP Encoding
- 去掉 Knowledge Graph Encoding
- 去掉 Fine-grained Alignment

结果显示，完整 OKG-LLM 始终表现最好。移除知识图谱编码后性能下降最明显，说明 OKG 是模型性能提升的核心来源。移除细粒度对齐模块也会明显降低表现，说明简单拼接知识和时间序列嵌入不足以实现有效融合。

这证明本文的三个设计——时间序列编码、知识图谱编码、细粒度对齐——都是必要的。

### 8.5 知识图谱完整性分析

论文第 9 页的表 IV 检验了移除不同实体类型后的性能变化，包括移除 Currents、Monsoons、Sea Areas 和 Oceans。完整 OKG-LLM 的平均 MSE 为 0.1311，平均 MAE 为 0.2388，均优于移除任一实体类型的版本。

其中移除洋流后的 MSE 上升到 0.1364，说明洋流知识对 SST 预测尤其重要。这符合海洋物理直觉，因为洋流直接影响热量输送和区域温度变化。

### 8.6 不同知识图谱嵌入方法比较

论文第 9 页的表 V 比较了 TransE、ConvE 和 RotatE。结果显示 TransE 略优，但三者总体差异不大。作者据此认为，只要知识图谱嵌入空间足够结构化，OKG-LLM 框架并不强依赖某一种特定 KGE 方法。

这说明本文的核心不只是选择 TransE，而是知识图谱编码与时序数据的对齐机制。

### 8.7 不同 LLM Backbone 比较

论文比较了 GPT-2、Llama2-7b、DeepSeek-R1 和 OceanGPT 四类 LLM backbone。结果显示，OKG-LLM 在不同 backbone 下均能提升预测表现。其中 GPT-2 作为 backbone 时总体最好，平均 MSE 为 0.131，平均 MAE 为 0.239。

一个有趣发现是，小规模 GPT-2 反而优于更大的 LLM。作者解释说，在 OKG-LLM 中，LLM 并不主要依赖其内部世界知识，而是处理已经对齐的知识增强数值表示。因此，稳定的序列建模能力比模型规模更关键。这个结果也进一步说明，性能提升主要来自知识对齐模块，而不是简单扩大 LLM。

### 8.8 可视化分析

论文第 10 页的图 5 展示了不同模型在全球范围内的 MAE 空间分布。OKG-LLM 的误差整体更低，尤其在 ENSO 相关的赤道太平洋等气候敏感区域表现更好。

论文第 10 页的图 6 展示了四个随机海域中真实 SST 与不同模型预测曲线的对比。OKG-LLM 的预测曲线与 ground truth 最接近，说明模型不仅在整体指标上更优，在具体区域的时间动态拟合上也更准确。

论文第 11 页的图 7 使用 t-SNE 可视化 embedding。仅使用时间序列的 baseline embedding 分布混乱，无法清晰区分不同海洋或洋流；而 OKG-LLM 生成的知识增强 embedding 形成了明显语义簇，同一海洋或同一洋流相关区域聚集更紧密。这说明知识图谱确实让模型学到了更有语义结构的表征。

## 9. 论文贡献总结

本文贡献主要有三点。

第一，提出了 **OKG-LLM 框架**，将结构化海洋知识、数值 SST 观测数据和 LLM 表征能力结合起来，用于全球 SST 预测。

第二，构建了首个面向 SST 预测的细粒度开放海洋知识图谱 **OKG**，包含区域、洋流、季风、海区和大洋等实体，以及多种物理和地理关系。

第三，通过大规模实验验证了 OKG-LLM 的有效性。结果显示它在多种预测长度、多个 LLM backbone、多个消融设置下均表现优越。

## 10. 未来可能改进方向

### 10.1 引入动态海洋知识图谱

论文目前使用静态 OKG，边界和关系主要来自长期气候平均信息。作者也在结论中指出，未来可以引入时间变化的海洋事件，例如台风、极端厄尔尼诺、海洋热浪、异常上升流、环流突变等。

进一步来说，可以构建 **Temporal Ocean Knowledge Graph**，使三元组带有时间戳或时间区间，例如“某区域在某周受台风影响”“某区域在某月处于 ENSO 异常阶段”。这可能显著提升极端事件期间的预测能力。

### 10.2 从静态边界到可学习边界

当前 OKG 的实体边界来自权威地图和 point-in-polygon 规则，具有可复现性，但海洋现象本身往往具有动态边界。未来可以让边界随季节、年份或气候状态变化，并使用遥感数据或再分析数据自动更新区域归属。

### 10.3 加入更多海洋变量

本文主要预测 SST，但海洋系统还受到风速、海表高度、盐度、海流速度、气压、降水、太阳辐射等变量影响。未来可以将 OKG-LLM 扩展为多变量海洋预测框架，统一预测 SST、CHL-A、海表高度、海冰浓度等多种海洋要素。

### 10.4 结合物理约束与知识图谱

OKG-LLM 引入了符号领域知识，但还没有显式加入热量守恒、流体动力学、能量平衡等物理约束。未来可以结合 physics-informed loss 或神经微分方程，使预测不仅符合统计规律和知识图谱关系，也符合海洋物理方程。

### 10.5 更强的知识图谱构建与验证机制

当前 OKG 依赖人工整理和权威资料数字化。未来可以进一步自动化构图，例如利用海洋论文、NOAA 报告、遥感产品说明文档自动抽取实体、关系和边界。同时需要设计知识质量评估机制，检测冲突三元组、过时知识和区域映射错误。

### 10.6 可解释性增强

OKG-LLM 的知识增强特性天然具有一定可解释性，但论文主要通过 embedding 可视化和消融验证其有效性。未来可以输出区域预测时最重要的知识路径，例如“该区域预测升温主要由某洋流、某季风和某海区关系贡献”，从而增强模型在海洋科学中的可信度。

### 10.7 面向下游应用的风险预测

SST 预测本身可以服务于极端天气、渔业资源、珊瑚白化、海洋热浪等任务。未来可以把 OKG-LLM 扩展到事件级预测，例如海洋热浪预警、ENSO 异常检测、台风增强风险评估等，使模型更贴近实际应用。

------

## 11. 总体评价

这篇论文的价值在于，它没有简单地把 LLM 套用到 SST 时间序列预测，而是明确指出了海洋领域知识与数值观测之间的粒度差异，并提出了知识图谱编码与区域级细粒度对齐机制。实验结果充分说明，**结构化领域知识是提升复杂科学预测任务的重要补充**。从计算机领域看，本文可被视为 “KG + LLM + Time Series Forecasting” 在海洋科学中的一个系统性范例；从海洋智能角度看，它为数据驱动模型融入可解释物理知识提供了可复用框架。
