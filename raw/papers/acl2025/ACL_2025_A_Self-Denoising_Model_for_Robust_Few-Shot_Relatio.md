# 泛读笔记：B0_s → μ+μ- 衰变的首次观测

## 文章基本信息

- **标题**: Observation of the rare B0_s → μ+μ- decay from the combined analysis of CMS and LHCb data
- **作者**: The CMS and LHCb Collaborations（CERN CMS和LHCb实验合作组）
- **单位**: 欧洲核子研究中心（CERN）及全球数百个研究机构
- **发表信息**: 
  - CERN编号: CMS-BPH-13-007, LHCb-PAPER-2014-049, CERN-PH-EP-2014-220
  - 发布日期: 2015年5月13日
  - arXiv: 1411.4413v2 [hep-ex] (2015年8月17日)
  - 发表期刊: Nature (2015)

## 一句话总结

本文首次实现了B0_s → μ+μ-衰变的观测（统计显著性超过6σ），并给出了B0 → μ+μ-衰变的证据（3σ），通过联合分析CMS和LHCb在LHC Run I期间收集的质子-质子碰撞数据，测量结果与标准模型预测高度一致。

## 背景

### 标准模型框架
标准模型（Standard Model, SM）描述了基本粒子及其通过强相互作用、电磁相互作用和弱相互作用进行的交互。标准模型对可测量量提供了精确预测，可通过实验验证。

### B介子物理学
B0_s和B0介子是通过弱相互作用衰变的不稳定粒子。B0_s介子由一个反b夸克和一个s夸克组成（质量约5367 MeV/c²），B0介子由一个反b夸克和一个d夸克组成（质量约5280 MeV/c²）。

### 味改变中性流（FCNC）
在基本层面，Z⁰玻色子不能直接耦合到不同味道的夸克，即不存在直接的"味改变中性流"（FCNC）。因此，B0_s → μ+μ-衰变在树图级别是被禁止的。然而，该衰变可以通过高阶（圈图）过程发生，如图中1d和1e所示的penguin图和箱图。

### 理论预测
标准模型对这些稀有衰变的分支比进行了可靠计算，考虑了高阶电磁和强相互作用效应，并使用格点QCD计算B介子衰变常数：
- B(B0_s → μ+μ-)_SM = (3.66 ± 0.23) × 10⁻⁹
- B(B0 → μ+μ-)_SM = (1.06 ± 0.09) × 10⁻¹⁰

这意味着每产生十亿个B0_s介子约有4个会发生B0_s → μ+μ-衰变，而每产生一百亿个B0介子约有1个会发生B0 → μ+μ-衰变。

## 动机

### 寻找超出标准模型的新物理
标准模型虽然通过了众多实验检验，但无法解释一些宇宙的基本问题，例如：
- 暗物质的存在（由宇宙学数据证实）
- 物质-反物质不对称性的起源

许多超出标准模型的理论（BSM）预言新粒子和新现象可以显著改变B0_s → μ+μ-和B0 → μ+μ-的分支比，特别是包含额外希格斯玻色子的理论。

### 分支比测量的意义
1. **偏离标准模型预测**：任何显著偏差都将指示标准模型需要扩展的方向
2. **与标准模型一致**：可对BSM理论提供严格约束
3. **分支比比率R**：R ≡ B(B0 → μ+μ-)/B(B0_s → μ+μ-)_SM = 0.0295⁺⁰·⁰⁰²⁸₋₀·₀₀₂₅，是区分不同BSM理论的有力判据

## 相关工作

### 历史搜索历程
过去三十多年，多个实验合作组对这两个稀有衰变进行了搜索：
- CLEO, ARGUS, UA1, L3, CDF, DØ, Belle, BaBar, ATLAS, LHCb, CMS

### LHC Run I之前的进展
- 2012年：LHCb合作组首次给出了B0_s → μ+μ-衰变的证据
- 2013年：CMS和LHCb分别发表了基于完整Run I数据的结果，精度相当且一致性良好
- 但单个实验的结果精度不足以构成B0_s衰变的确定性观测

### 本文创新点
首次将CMS和LHCb的数据进行联合分析，同时利用两个实验的统计能力，并处理它们之间的主要关联。

## 方法

### 实验装置

**CMS探测器**
- 紧凑缪子螺线管探测器，设计用于搜索100 GeV/c²至几TeV/c²的新粒子
- 13米长、6米直径的超导螺线管磁铁，磁场强度3.8 T
- 硅跟踪系统，包括像素探测器和条状探测器
- 量能器（电磁和强子）和缪子探测器嵌入钢磁轭中
- B0_s → μ+μ-的质量分辨率：32-75 MeV/c²（取决于角度）

**LHCb探测器**
- 专门优化用于研究b夸克粒子的物质-反物质不对称性和稀有衰变
- 覆盖10-300 mrad的小角度区域
- 高精度跟踪系统，包括硅顶点探测器和偶极磁铁（4 T·m）
- 环形成像Cherenkov探测器用于带电强子鉴别
- 均匀的质量分辨率约25 MeV/c²

### 数据采集
- 2011年：质子-质子碰撞，质心能量7 TeV
- 2012年：质心能量8 TeV
- CMS积分亮度：25 fb⁻¹
- LHCb积分亮度：3 fb⁻¹
- 相当于两实验总共产生约10¹²个B0_s和B0介子

### 分析策略

**候选事例选择**
1. 重建两个相反电荷的缪子轨迹
2. 要求缪子对形成共同的顶点，且与原初顶点有位移
3. 要求B候选体的动量矢量指向原初顶点

**提升决策树（BDT）**
- 结合约十个鉴别变量构建多变量判别器
- 变量包括：缪子轨迹质量、运动学变量（横向动量）、衰变顶点拓扑、隔离变量等
- CMS使用数据中的边带区域作为本底训练样本
- LHCb使用模拟事件进行训练

**本底抑制**
- **组合本底**：两个随机缪子的组合，主要来自两个不同b强子的半轻子衰变
- **半轻子本底**：如B⁰ → π⁻μ⁺ν，其中中微子不可探测，带电π介子被误鉴别为缪子
- **峰本底**：强子两体衰变（如B⁰ → K⁺π⁻）中两个强子都被误鉴别为缪子

**归一化**
- 使用B⁺ → J/ψK⁺衰变作为归一化通道
- 需要b夸克强子化为B⁺与B⁰_s的概率比fd/fs
- LHCb测量的fd/fs = 3.86 ± 0.22

### 联合拟合

**同时拟合**
- 对CMS和LHCb的20个BDT分类（CMS 12个 + LHCb 8个）进行无偏扩展最大似然拟合
- 共同参数：B(B0_s → μ+μ-)、B(B0 → μ+μ-)、fd/fs、B(B⁺ → J/ψK⁺)
- 使用高斯约束处理系统不确定性

**统计方法**
- 使用Wilks定理计算显著性
- 使用Feldman-Cousins方法确定B⁰分支比的置信区间

## 实验设计

### 触发系统
- LHCb：触发p_T > 1.5 GeV/c的缪子
- CMS：触发两个缪子，p_T > 4(3) GeV/c（主导/次主导缪子）

### 分类策略
- 按实验（CMS/LHCb）分类
- 按BDT判别值范围分类
- CMS额外按数据采集期和探测器区域（中心区/前向区）分类

### 质量拟合范围
- CMS：[4.9, 5.9] GeV/c²
- LHCb：[4.9, 6.0] GeV/c²

## 结果与分析

### 分支比测量结果

$$B(B^0_s \rightarrow \mu^+\mu^-) = \left(2.8^{+0.7}_{-0.6}\right) \times 10^{-9}$$

$$B(B^0 \rightarrow \mu^+\mu^-) = \left(3.9^{+1.6}_{-1.4}\right) \times 10^{-10}$$

其中不确定性包含统计和系统误差，系统误差分别贡献35%和18%。

### 统计显著性
- B0_s → μ+μ-：6.2σ（使用Wilks定理）
- B0 → μ+μ-：3.0σ（使用模拟实验）

### 与标准模型比较

| 参数 | 测量值 | SM预测 | 兼容性 |
|------|--------|--------|--------|
| B(B0_s → μ+μ-) | 2.8×10⁻⁹ | (3.66±0.23)×10⁻⁹ | 1.2σ |
| B(B0 → μ+μ-) | 3.9×10⁻¹⁰ | (1.06±0.09)×10⁻¹⁰ | 2.2σ |
| R = B0/B0_s | 0.14⁺⁰·⁰⁸₋₀·₀₆ | 0.0295⁺⁰·⁰⁰²⁸₋₀·₀₀₂₅ | 2.3σ |

### 关键结论
1. 首次确定性观测到B0_s → μ+μ-衰变
2. 首次获得B0 → μ+μ-衰变的3σ证据
3. 两个测量均与标准模型预测统计兼容
4. 对超出标准模型理论提供了严格约束

## 未来改进方向

### 提高测量精度
- LHC Run II（2015年起）：质心能量13 TeV，B0_s和B0介子产生率约增加一倍
- 更大的数据样本将显著提高分支比测量精度

### 物理目标
- 精确测量B0_s → μ+μ-的有效寿命
- 测量衰变中的CP破坏效应
- 寻找可能的角分布异常

### 理论联系
- 更精确的格点QCD计算
- 探索与B→K*μ⁺μ⁻等其他稀有衰变的联合分析
- 对BSM模型提供更严格约束

### 实验改进
- 升级探测器以提高触发效率和低动量缪子重建能力
- 减少系统不确定性，特别是粒子鉴别和归一化相关的不确定性

## 总结

本文是粒子物理学的重要里程碑，首次实现了对极其稀有B0_s → μ+μ-衰变的确定性观测。通过CMS和LHCb的联合分析，不仅验证了标准模型在这一极端稀有过程中的预测，还为寻找新物理提供了强有力的实验约束。这一成果开启了精确测量B介子稀有衰变性质的新阶段。
