## 背景

### 标准模型与粒子物理学

标准模型（Standard Model, SM）是描述基本粒子及其通过强相互作用、电磁相互作用和弱相互作用进行相互作用的基本理论。自1970年代以来，实验粒子物理学家以越来越高的精度检验标准模型的预测。标准模型通过了实验的关键检验，但它并未解决关于宇宙本质的一些深刻问题，例如：

- **暗物质的存在**：由宇宙学数据证实，但标准模型无法容纳
- **物质与反物质不对称性的起源**：大爆炸后导致目前宇宙中少量物质得以存留的机制

许多理论试图超越标准模型（Beyond the Standard Model, BSM）来解决这些开放问题。

### B介子的稀有衰变

B0s和B0介子是通过弱相互作用衰变的不稳定粒子。测量这些介子到双μ子（μ+μ−）末态的稀有衰变的分支比具有特别重要的意义，因为在标准模型中这些衰变极其罕见：

- **B0s → μ+μ−**：每产生十亿个B0s介子约发生4次
- **B0 → μ+μ−**：每产生一百亿个B0介子约发生1次

这些分支比由于以下原因被高度抑制：
1. **味改变中性流（FCNC）禁止**：Z0玻色子不能直接耦合到不同味的夸克
2. **高阶过程**：必须通过图1d和1e所示的更高阶的FCNC过程发生
3. **螺旋度抑制**：由于角动量考虑
4. **CKM矩阵元抑制**：涉及不同代夸克之间的转换

标准模型预测（考虑高阶电磁和强相互作用效应，并使用格点QCD计算B介子衰变常数）为：

$$B(B^0_s \rightarrow \mu^+\mu^-)_{SM} = (3.66 \pm 0.23) \times 10^{-9}$$

$$B(B^0 \rightarrow \mu^+\mu^-)_{SM} = (1.06 \pm 0.09) \times 10^{-10}$$

### 超越标准模型理论

许多BSM理论包含可以显著改变标准模型分支比的新现象和新粒子，特别是：
- 包含额外希格斯玻色子的理论
- 超对称理论（SUSY）
- 最小味破坏（Minimal Flavour Violation, MFV）理论

分支比与标准模型预测的任何偏差都将为如何扩展标准模型提供方向。

## 动机

### 科学目标

1. **首次观测B0s → μ+μ−衰变**：在LHC开始运行之前，没有发现这两种衰变模式的任何证据，分支比上限比标准模型预测高出一个数量级。

2. **检验标准模型**：测量结果与标准模型预测的一致性可以对这些理论提供严格约束。

3. **区分BSM理论**：两种衰变分支比的比值R ≡ B(B0 → μ+μ−)/B(B0s → μ+μ−) 在标准模型中预测为0.0295^{+0.0028}_{-0.0025}，而具有最小味破坏性质的BSM理论预测与SM相同，因此该比值可以有效区分不同BSM理论。

4. **组合分析的统计优势**：CMS和LHCb单独测量的精度相当且结果一致，但单独结果都没有足够的精度来构成对B0s衰变的首次确定性观测。通过组合两个数据集可以充分利用统计能力并考虑它们之间的主要相关性。

### 实验数据

- **数据来源**：2011年质子-质子碰撞（质心能量7 TeV）和2012年（质心能量8 TeV）
- **积分亮度**：
  - CMS：25 fb⁻¹
  - LHCb：3 fb⁻¹
- **总B0s和B0介子产生数**：约10¹²个
- **预期观测衰变数**（假设标准模型分支比）：
  - B0s → μ+μ−：约100个
  - B0 → μ+μ−：约10个

## 方法

### 实验装置

#### CMS探测器
- **设计目标**：搜索质量范围从约100 GeV/c²到几 TeV/c²的未知重粒子
- **特点**：覆盖大角度和动量范围重建高质量态
- **磁场**：3.8 T的超导螺线管
- **内部追踪**：硅像素和硅条探测器
- **μ子识别**：嵌入钢磁轭中的气体电离探测器
- **B0(s) → μ+μ−质量分辨率**：32-75 MeV/c²（取决于μ子相对于束流的方向）

#### LHCb探测器
- **设计目标**：研究含有b夸克的粒子的物质-反物质不对称性和稀有衰变
- **特点**：优化探测小角度区域的b强子产生
- **磁场**：4 T·m的偶极磁铁
- **追踪系统**：硅条顶点探测器、硅条探测器、漂移管
- **μ子识别**：交替的铁层和多丝正比室
- **B0(s) → μ+μ−质量分辨率**：约25 MeV/c²（几乎与角度无关）

### 分析策略

#### 候选事件重建
1. **μ子识别**：利用μ子能够穿透密集材料（如钢）并在其中嵌入的探测器中产生信号的特性
2. **重建**：重建两个相反电荷粒子（识别为μ子）的轨迹，形成共同顶点
3. **初级顶点位移要求**：B0(s)介子寿命约1.5 ps，在LHC产生的动量从几 GeV/c到约100 GeV/c，因此可以旅行数厘米才衰变。要求"衰变顶点"相对于"产生顶点"（两个质子碰撞点）有位移
4. **动量方向要求**：B0(s)候选者动量矢量的负方向必须指向产生顶点

#### 多变量分析（BDT）
将多个判别变量组合成提升决策树（Boosted Decision Tree, BDT）：
- μ子轨迹质量变量
- 运动学变量（单个μ子和B0(s)候选者的横向动量）
- 衰变顶点拓扑和拟合质量变量（如候选者衰变长度）
- 隔离变量（测量两个μ子或其位移顶点附近其他粒子的活动）

#### 本底抑制
1. **组合本底**：两个随机μ子的组合，主要来自两个不同b强子的半轻子衰变
2. **半轻子本底**：如B0 → π−μ+ν（ν不可探测，带电π被误识别为μ子）
3. **峰状本底**：强子两体衰变（如B0 → K+π−），两个强子都被误识别为μ子

#### 分支比测量

使用**B+ → J/ψK+**衰变作为归一化通道：
$$B(B^0_s \rightarrow \mu^+\mu^-) = \frac{N_{B^0_s \rightarrow \mu^+\mu^-}}{N_{norm.}} \times \frac{f_d}{f_s} \times \frac{\varepsilon_{norm.}}{\varepsilon_{B^0_s \rightarrow \mu^+\mu^-}} \times B_{norm.}$$

其中：
- $f_d/f_s$ = b夸克形成B0与形成B0s介子的概率比
- ε表示总事件探测效率（包括几何接受度、触发、重建和分析选择）

### 组合拟合

- **方法**：对CMS和LHCb数据同时进行无偏扩展最大似然拟合
- **共同参数**：两个信号通道的分支比、$f_d/f_s$、归一化通道B+ → J/ψK+的分支比
- **分类**：根据实验（CMS或LHCb）和BDT判别值分类
  - CMS：12个类别（根据数据采集期、μ子角度区域、BDT值）
  - LHCb：8个类别（根据BDT值）
- **拟合范围**：B0s质量附近约±500 MeV/c²的双μ子不变质量

### 数据采集

|------|----------|------|----------|
| CMS | 7 TeV | 2011 | - |
| CMS | 8 TeV | 2012 | - |
| LHCb | 7 TeV | 2011 | - |
| LHCb | 8 TeV | 2012 | - |
| **总计** | - | - | **25 fb⁻¹ (CMS) + 3 fb⁻¹ (LHCb)** |

### 触发条件

- **LHCb**：触发pT > 1.5 GeV/c的μ子
- **CMS**：触发两个μ子，pT > 4(3) GeV/c（主导/次主导μ子）

### 分析程序

1. **盲分析**：两个实验都将包含B0s和B0信号的小质量区间保密，直到所有选择标准确定
2. **BDT训练**：
   - CMS：使用数据边带区间的组合本底和模拟信号事件
   - LHCb：使用模拟事件进行本底和信号训练
3. **同时拟合**：对20个类别的双μ子不变质量分布进行无偏扩展最大似然拟合

## 结果与分析

### 主要测量结果

**组合拟合结果**：

$$B(B^0_s \rightarrow \mu^+\mu^-) = \begin{pmatrix} 2.8 \\ -0.6 \end{pmatrix} \times 10^{-9}$$

$$B(B^0 \rightarrow \mu^+\mu^-) = \begin{pmatrix} 3.9 \\ -1.4 \end{pmatrix} \times 10^{-10}$$

其中不确定性包括统计和系统来源，后者分别贡献了B0s和B0信号总不确定性的35%和18%。

### 统计显著性

- **B0s → μ+μ−**：6.2σ（使用Wilks定理计算）
- **B0 → μ+μ−**：3.0σ（使用 Feldman-Cousins 程序）
- **预期中位显著性**（假设SM分支比）：
  - B0s：7.4σ
  - B0：0.8σ

### 与标准模型比较

- **分支比与SM预测的比值**：
  - $S_{B^0_s} = B(B^0_s \rightarrow \mu^+\mu^-)/B(B^0_s \rightarrow \mu^+\mu^-)_{SM} = 0.76^{+0.20}_{-0.18}$
  - $S_{B^0} = B(B^0 \rightarrow \mu^+\mu^-)/B(B^0 \rightarrow \mu^+\mu^-)_{SM} = 3.7^{+1.6}_{-1.4}$

- **兼容性**：
  - B0s → μ+μ−：与SM在1.2σ水平兼容
  - B0 → μ+μ−：与SM在2.2σ水平兼容

- **分支比比值**：
  - $R = B(B^0 \rightarrow \mu^+\mu^-)/B(B^0_s \rightarrow \mu^+\mu^-) = 0.14^{+0.08}_{-0.06}$
  - 与SM在2.3σ水平兼容

### 置信区间

使用Feldman-Cousins程序：
- **B0 → μ+μ−的±1σ区间**：[2.5, 5.6] × 10⁻¹⁰
- **B0 → μ+μ−的±2σ区间**：[1.4, 7.4] × 10⁻¹⁰

## 未来可能改进的方向

### 1. 增加数据量

- LHC于2015年恢复数据采集，记录质心能量13 TeV的质子-质子碰撞
- 这将使B0s和B0介子的产生率大约翻倍
- 预期将显著提高测量精度

### 2. 改进探测器

- 升级LHCb探测器以提高效率和分辨率
- 改进CMS的μ子识别系统

### 3. 分析方法改进

- 优化BDT变量选择
- 减少系统不确定性
- 更精确的归一化通道测量

### 4. 物理目标

- 测量B0s → μ+μ−的有效寿命
- 测量衰变中的CP破坏效应
- 寻找可能的角分布异常（指向BSM物理）
- 更严格的BSM理论约束

### 5. 扩展测量

- 测量B0s介子的轻子味普适性破坏
- 探索其他稀有B衰变模式
- 与其他精确测量（如B→K*μ+μ−）联合分析

## 总结

本文是粒子物理学的一个重要里程碑，首次以超过6σ的显著性观测到了稀有B0s → μ+μ−衰变，这是标准模型中最稀有的衰变之一。CMS和LHCb的组合分析不仅首次确认了这一衰变的存在，还以最高精度测量了其分支比，结果与标准模型预测高度一致。这一测量对超越标准模型理论施加了最严格的约束，特别是对具有额外希格斯玻色子的理论。随着LHC在更高能量下继续运行，对这些关键标准模型检验的精度将进一步提升。
