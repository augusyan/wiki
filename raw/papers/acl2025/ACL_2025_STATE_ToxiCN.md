# 文献泛读笔记

- **作者**: The CMS and LHCb Collaborations
- **单位**: CERN (欧洲核子研究组织)，以及来自全球众多研究机构的参与人员

  - CERN Report: CMS-BPH-13-007, LHCb-PAPER-2014-049, CERN-PH-EP-2014-220

  - arXiv: 1411.4413v2 [hep-ex], 2015年8月17日
- **代码链接**: 无

## 一句话总结

本文首次实现了B0s → μ+μ− 稀有衰变的观测（统计显著性超过6σ），并给出了B0 → μ+μ− 衰变的最佳证据（3σ），两个测量结果均与标准模型预测一致，为超越标准模型的理论提供了严格约束。

---

## 背景

标准模型（SM）是描述基本粒子及其相互作用（强相互作用、电磁相互作用和弱相互作用）的理论框架。标准模型对可测量量提供了精确预测，其中B0s和B0介子衰变到双μ子（μ+μ−）的分支比尤为引人注目，因为它们对超越标准模型的理论（BSM）具有极高的敏感性。

标准模型预测B0s → μ+μ− 和 B0 → μ+μ− 衰变极为稀有：
- B0s → μ+μ−：每产生十亿个B0s介子约有4个发生此衰变
- B0 → μ+μ−：每产生一百亿个B0介子约有1个发生此衰变

在大型强子对撞机（LHC）开始运行之前，这两个衰变模式均未被发现，其分支比上限比标准模型预测高出一个数量级。

---

## 动机

1. **探索物理新现象**：标准模型虽然通过了众多实验检验，但无法解释暗物质的存在和宇宙中物质-反物质不对称性的起源。许多超越标准模型的理论（如超对称理论）预言新粒子和新现象可以显著改变这些稀有衰变的分支比。

2. **精确检验标准模型**：测量这些稀有衰变的分支比可以验证标准模型的精确预测，若测量值与预测不符，将为标准模型的扩展提供方向；若相符，则可对BSM理论施加严格约束。

3. **分支比比率的独特价值**：两个衰变分支比的比率 R ≡ B(B0 → μ+μ−) / B(B0s → μ+μ−) 在标准模型中预测为 0.0295^{+0.0028}_{-0.0025}，具有最小味破坏（MFV）性质的BSM理论预测值与SM相同，因此该比率是区分不同BSM理论的有力工具。

---

## 相关工作

1. **LHCb 2012年结果**：LHCb合作组在2012年首次给出了B0s → μ+μ− 衰变的证据。

2. **CMS和LHCb分别发表的结果**：2013年，CMS和LHCb分别发表了基于2011年（7 TeV）和2012年（8 TeV）数据的独立测量结果，二者精度相当且一致性良好，但单独任一结果都不足以构成对B0s → μ+μ− 衰变的确定性观测。

3. **历史搜索**：过去三十多年中，共有11个实验合作组参与搜索该衰变，包括CLEO、ARGUS、UA1、CDF、L3、DØ、Belle、BaBar、LHCb、CMS和ATLAS。

## 方法

### 1. 数据采集
- CMS和LHCb探测器分别采集了2011年（7 TeV）和2012年（8 TeV）的质子-质子碰撞数据
- 总积分亮度：CMS为25 fb⁻¹，LHCb为3 fb⁻¹
- 相当于两实验总共产生约10¹²个B0s和B0介子

### 2. 信号重建
- 通过重建两个带电粒子（被识别为μ子）的轨迹形成候选衰变
- 要求候选衰变的顶点相对于原初顶点（PV）有位移
- 要求B0(s)候选粒子的动量矢量指向原初顶点

### 3. 背景抑制
- **组合背景**：来自两个不同b强子的半轻子衰变的随机μ子组合，通过双μ子不变质量mμ+μ−和B0(s)介子衰变的已知特征来区分
- **半轻子背景**：如B0 → π−μ+ν（ν不可探测，π被误识别为μ）等
- **峰化背景**：强子两体衰变（如B0 → K+π−）中两个强子都被误识别为μ子

### 4. 多元分析
- 使用提升决策树（BDT）将多个区分信号和背景的变量组合
- CMS使用数据中的质量侧带来训练背景，模拟事件训练信号
- LHCb使用模拟事件训练信号和背景

### 5. 分支比计算
- 使用B+ → J/ψK+ 衰变作为归一化通道
- 需要b夸克强子化为B+和B0s介子的比率fd/fs
- 公式：$$B(B^0_s \rightarrow \mu^+\mu^-) = \frac{N_{B^0_s\rightarrow\mu^+\mu^-}}{N_{norm.}} \times \frac{f_d}{f_s} \times \frac{\varepsilon_{norm.}}{\varepsilon_{B^0_s\rightarrow\mu^+\mu^-}} \times B_{norm.}$$

### 6. 联合拟合
- 对CMS和LHCb的20个类别（按实验、BDT值等分类）同时进行无偏扩展最大似然拟合
- 两个分支比作为共同参数自由变化
- fd/fs和B+ → J/ψK+ 分支比作为共同约束参数

## 实验设计

### CMS探测器
- 13米长、6米直径的超导螺线管磁铁，磁场3.8 T
- 硅跟踪系统：像素探测器（4.3-10.7 cm）和硅条探测器（25-110 cm）
- 量能器：电磁量能器和强子量能器
- μ子探测器：嵌入在钢磁轭中的气体电离探测器
- B0(s) → μ+μ− 衰变的质量分辨率：32-75 MeV/c²（取决于μ子相对于束流的方向）

### LHCb探测器
- 优化用于研究b夸克粒子的产生和衰变
- 高精度跟踪系统：硅条顶点探测器、偶极磁铁（4 T·m）、下游硅条探测器
- 环形成像Cherenkov探测器用于带电强子鉴别
- μ子探测系统：交替的铁层和多丝正比室
- 统一的质量分辨率约25 MeV/c²

### 触发系统
- LHCb：触发pT > 1.5 GeV/c的μ子
- CMS：触发两个μ子，pT > 4(3) GeV/c（领头/次领头μ子）

## 结果与分析

### 分支比测量结果
$$B(B^0_s \rightarrow \mu^+\mu^-) = \left(2.8^{+0.7}_{-0.6}\right) \times 10^{-9}$$
$$B(B^0 \rightarrow \mu^+\mu^-) = \left(3.9^{+1.6}_{-1.4}\right) \times 10^{-10}$$

其中不确定性包含统计和系统误差，系统误差分别贡献了35%和18%的总不确定度。

### 统计显著性
- B0s → μ+μ−：6.2σ（使用Wilks定理计算）
- B0 → μ+μ−：3.2σ（使用Wilks定理），3.0σ（使用 Feldman-Cousins 方法）

### 与标准模型比较
- SM预测：$B(B^0_s \rightarrow \mu^+\mu^-)_{SM} = (3.66 \pm 0.23) \times 10^{-9}$
- SM预测：$B(B^0 \rightarrow \mu^+\mu^-)_{SM} = (1.06 \pm 0.09) \times 10^{-10}$

测量值与标准模型预测的兼容性：
- B0s → μ+μ−：1.2σ
- B0 → μ+μ−：2.2σ

### 分支比比率
$$R = 0.14^{+0.08}_{-0.06}$$
与SM预测的兼容性：2.3σ

### 归一化参数
$$S_{B^0_s} \equiv B(B^0_s \rightarrow \mu^+\mu^-)/B(B^0_s \rightarrow \mu^+\mu^-)_{SM} = 0.76^{+0.20}_{-0.18}$$
$$S_{B^0} \equiv B(B^0 \rightarrow \mu^+\mu^-)/B(B^0 \rightarrow \mu^+\mu^-)_{SM} = 3.7^{+1.6}_{-1.4}$$

## 未来可能改进方向

1. **更高统计量**：LHC在2015年后以13 TeV质心能量运行，B0s和B0介子的产生率约增加一倍，将显著提高测量精度

2. **改进探测器**：CMS和LHCb探测器的升级将提高探测效率和分辨率

3. **更精确的理论计算**：减少理论不确定性，特别是格点QCD对B介子衰变常数的计算

4. **测量有效寿命**：B0s → μ+μ− 有效寿命的测量可以进一步区分不同BSM模型

5. **测量角度分布**：分析衰变的角度分布可以提取额外的CP破坏信息

6. **寻找其他稀有衰变**：如B0s → μ+μ−μ+μ− 等

---

## 总结

本文是CMS和LHCb两个实验首次联合分析数据来获得统计显著性的观测结果，标志着B0s → μ+μ− 衰变搜索长达三十多年历程的结束和精确测量时代的开始。两个测量结果均与标准模型预测一致，这对超越标准模型的理论施加了严格约束，特别是对具有大tanβ的超对称模型等理论。
