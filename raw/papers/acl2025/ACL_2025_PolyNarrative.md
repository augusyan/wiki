# 泛读笔记

## 标题

**Observation of the rare B0s → μ+μ− decay from the combined analysis of CMS and LHCb data**
（基于CMS和LHCb数据的组合分析观测稀有B0s → μ+μ−衰变）

## 作者与单位

**作者**：CMS和LHCb合作组（The CMS and LHCb Collaborations）

**单位**：欧洲核子研究组织（CERN）及其全球合作机构，包括来自世界各地数百所研究机构的数千名物理学家。

## 一句话总结

本文首次实现了B0s → μ+μ−稀有衰变的观测（统计显著性超过6σ），并给出了B0 → μ+μ−衰变的最佳证据（3σ），两个测量结果均与标准模型预测一致。

## 背景

标准模型（SM）是描述基本粒子及其相互作用（强相互作用、电磁相互作用和弱相互作用）的理论框架。它对可测量量提供了精确预测，可通过实验验证。B0s介子和B0介子衰变为两个带相反电荷的μ子（μ+和μ−）的分支比尤其重要，因为它们对标准模型扩展理论（BSM）非常敏感。

标准模型预测B0s → μ+μ−和B0 → μ+μ−衰变非常稀有：每产生十亿个B0s介子约有4个发生B0s → μ+μ−衰变，每产生一百亿个B0介子约有1个发生B0 → μ+μ−衰变。在大型强子对撞机（LHC）开始运行之前，这两个衰变模式都未被观测到，分支比上限比标准模型预测高出一个数量级。

---

## 动机

1. **寻找标准模型扩展的线索**：如果观测到的分支比与标准模型预测存在显著差异，将为如何扩展标准模型提供方向。

2. **检验稀有味改变中性流（FCNC）过程**：B0s → μ+μ−衰变是通过高阶味改变中性流（FCNC）过程发生的，标准模型中禁止直接的FCNC，但可以通过高阶图实现。

3. **区分不同BSM理论**：两种衰变分支比的比值R ≡ B(B0 → μ+μ−)/B(B0s → μ+μ−)在标准模型中预测为0.0295+0.0028/−0.0025，这一比值在具有最小味破坏（MFV）性质的BSM理论中与SM相同，可用于区分不同理论。

4. **长期搜索的历史意义**：寻找这两个衰变已持续三十多年，多个实验（ CLEO, ARGUS, UA1, CDF, L3, DØ, Belle, BaBar, ATLAS, LHCb, CMS）参与其中。

---

## 相关工作

1. **2012年LHCb首次证据**：LHCb合作组在2012年首次给出了B0s → μ+μ−衰变的证据。

2. **2013年单独测量**：
   - CMS发表了基于全部7 TeV（2011年）和8 TeV（2012年）数据的测量结果。
   - LHCb也发表了独立的测量结果。
   - 两个单独测量的精度相当且结果一致，但都未达到首次确定性观测B0s衰变的精度。

3. **本文的创新点**：首次将CMS和LHCb的数据进行联合分析，同时利用两个实验的统计数据并考虑它们之间的主要相关性。

## 方法

### 1. 数据采集
- 2011年质子-质子碰撞：质心能量7 TeV
- 2012年质子-质子碰撞：质心能量8 TeV
- CMS积分亮度：25 fb⁻¹
- LHCb积分亮度：3 fb⁻¹

### 2. 分析策略
两个实验采用相似的数据分析策略：
- **候选事例重建**：通过组合两个带相反电荷且被识别为μ子的重建径迹（tracks）来寻找与B0(s) → μ+μ−相容的衰变。
- **信号-背景分离**：利用双μ子不变质量mμ+μ−和B0(s)介子衰变的已知特性来分离真实B0(s) → μ+μ−衰变与两个μ子的随机组合（组合背景）。
- **顶点位移要求**：由于B0(s)介子寿命约1.5 ps，在LHC产生时动量在几GeV/c到~100 GeV/c之间，它们在衰变前可移动数厘米。因此要求B0(s) → μ+μ−的"衰变顶点"相对于"产生顶点"（两个质子碰撞点）有位移。
- **提升决策树（BDT）**：将多个判别变量组合成BDT，包括：μ子径迹质量、横向动量、衰变顶点拓扑和拟合质量、隔离变量等。

### 3. 背景估计
- **组合背景**：通过不变质量侧带插值估计
- **半轻子背景**：如B0 → π−μ+ν（ν不可探测，π被误识别为μ）
- **峰状背景**：误识别的强子两体衰变，如B0 → K+π−（两个强子都被误识别为μ）

### 4. 联合拟合
- 将CMS和LHCb数据同时拟合，共同拟合参数包括两个信号道的分支比、强子化分数比fd/fs和归一化道B+ → J/ψK+的分支比。
- 使用无偏扩展最大似然拟合，对20个类别（CMS 12个，LHCb 8个）的双μ子不变质量分布进行拟合。

## 实验设计

### CMS探测器
- 设计用于搜索质量约100 GeV/c²到几TeV/c²的新粒子
- 13米长、6米直径的超导螺线管磁铁，磁场3.8 T
- 硅跟踪系统：像素探测器（4.3-10.7 cm）和硅条探测器（25-110 cm）
- 量能器：电磁量能器和强子量能器
- μ子探测：嵌入钢磁轭中的气体电离探测器
- B0(s) → μ+μ−衰变的质量分辨率：32-75 MeV/c²（取决于μ子相对于束流的方向）

### LHCb探测器
- 专门优化用于研究b夸克粒子的物质-反物质不对称和稀有衰变
- 覆盖10-300 mrad小角区域
- 高精度跟踪系统：硅条顶点探测器、偶极磁铁（4 T·m）、下游硅条探测器
- 环形成像Cherenkov探测器用于带电强子鉴别
- μ子探测系统：交替的铁层和多丝正比室
- 均匀质量分辨率：约25 MeV/c²

## 结果与分析

### 分支比测量结果

$$B(B^0_s \rightarrow \mu^+\mu^-) = \left(2.8^{+0.7}_{-0.6}\right) \times 10^{-9}$$

$$B(B^0 \rightarrow \mu^+\mu^-) = \left(3.9^{+1.6}_{-1.4}\right) \times 10^{-10}$$

其中不确定性包含统计和系统误差，系统误差分别贡献了总不确定性的35%和18%。

### 统计显著性

- **B0s → μ+μ−**：6.2σ（使用Wilks定理计算）
- **B0 → μ+μ−**：3.0σ（使用 Feldman-Cousins方法）

假设标准模型分支比，预期中位显著性分别为7.4σ和0.8σ。

### 与标准模型比较

- SB0s SM ≡ B(B0s → μ+μ−)/B(B0s → μ+μ−)SM = 0.76+0.20/−0.18
- SB0 SM ≡ B(B0 → μ+μ−)/B(B0 → μ+μ−)SM = 3.7+1.6/−1.4
- 分支比与标准模型的兼容性：分别1.2σ和2.2σ
- 比值R = 0.14+0.08/−0.06，与标准模型（0.0295）在2.3σ水平兼容

### 关键结论

1. **首次观测**：首次确凿观测到B0s → μ+μ−衰变，统计显著性超过6σ
2. **最佳证据**：首次给出B0 → μ+μ−衰变的3σ证据
3. **与SM一致**：两个测量结果均与标准模型预测一致
4. **严格约束**：为BSM理论提供了严格约束

## 未来可能改进方向

1. **更高统计精度**：2015年LHC恢复运行后，质心能量提升至13 TeV，B0s和B0介子的产生率约增加一倍，将显著提高测量精度。

2. **改进探测器**：两个实验都在升级探测器以提高性能。

3. **测量有效寿命**：通过测量B0s → μ+μ−的有效寿命，可以进一步区分不同BSM模型。

4. **测量角度分布**：分析衰变的角度分布可以提供额外的CP破坏测量和BSM敏感性。

5. **提高系统精度**：减少系统误差，特别是与强子化分数比fd/fs和归一化道分支比相关的不确定性。

6. **分离B0和B0s**：提高质量分辨率以更好分离B0和B0s信号（质量差约87 MeV/c²）。

---

## 总结

本文是粒子物理学的重要里程碑，首次观测了标准模型预测的极稀有B0s介子到双μ子衰变。这一发现结束了长达三十多年的搜索历程，开启了精确测量该衰变性质的新阶段。两个实验的联合分析展示了合作在粒子物理学中的力量，测量结果与标准模型高度一致，为超出标准模型的新物理理论提供了严格的实验约束。
