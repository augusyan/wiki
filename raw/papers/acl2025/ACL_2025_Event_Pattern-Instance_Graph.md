# 泛读笔记：B0s → μ+μ− 衰变的首次观测

## 文章基本信息

- **标题**: Observation of the rare B0s → μ+μ− decay from the combined analysis of CMS and LHCb data
- **作者**: The CMS and LHCb Collaborations
- **单位**: CERN (欧洲核子研究组织)
- **发表信息**: 
  - arXiv:1411.4413v2 [hep-ex]
  - CERN-PH-EP-2014-220
  - CMS-BPH-13-007
  - LHCb-PAPER-2014-049
  - 发表日期：2015年5月13日

## 一句话总结

CMS和LHCb合作组联合分析了LHC Run I期间收集的质子-质子碰撞数据，首次观测到罕见的B0s → μ+μ− 衰变（统计显著性超过6σ），并获得了B0 → μ+μ− 衰变的证据（3σ），两个测量结果均与标准模型预测一致。

## 背景

标准模型（SM）描述了基本粒子及其通过强相互作用、电磁相互作用和弱相互作用的运动。标准模型对可测量量提供了精确预测，其中B0s和B0介子衰变到双μ子（μ+μ−）的分支比尤为引人注目，因为它们对标准模型的扩展理论具有极高的敏感性。

标准模型预测B0s → μ+μ− 和 B0 → μ+μ− 衰变极为罕见：每产生十亿个B0s介子约有4个发生B0s → μ+μ− 衰变，每产生一百亿个B0介子约有1个发生B0 → μ+μ− 衰变。在LHC开始运行之前，这两个衰变模式均未被发现，实验上限比标准模型预测高出一个数量级。

---

## 动机

B0s和B0介子通过弱相互作用衰变。测量这些介子到双μ子末态的稀有衰变分支比具有重要意义，原因如下：

1. **新物理探针**：这些衰变通过高阶味改变中性流（FCNC）过程发生，对标准模型扩展理论（如超对称模型、额外希格斯玻色子模型）非常敏感
2. **理论意义**：标准模型预测这些衰变被强烈抑制，任何与预测的偏差都可能指向新物理
3. **区分BSM理论**：两种衰变的分支比之比R ≡ B(B0 → μ+μ−)/B(B0s → μ+μ−) 可以有效区分不同的超出标准模型（BSM）理论

标准模型预测值为：
$$B(B^0_s \rightarrow \mu^+\mu^-)_{SM} = (3.66 \pm 0.23) \times 10^{-9}$$
$$B(B^0 \rightarrow \mu^+\mu^-)_{SM} = (1.06 \pm 0.09) \times 10^{-10}$$

## 相关工作

- 2012年，LHCb合作组首次给出了B0s → μ+μ− 衰变的证据
- CMS和LHCb分别发表了基于2011年（7 TeV）和2012年（8 TeV）数据的独立测量结果，精度相当且一致性良好
- 在此之前，超过11个实验组（包括CLEO、ARGUS、UA1、CDF、L3、DØ、Belle、BaBar、ATLAS等）寻找了这些衰变，持续超过30年

## 方法

### 实验装置

- **CMS探测器**：紧凑μ子螺线管探测器，设计用于搜索质量在100 GeV/c²至几 TeV/c²范围的新粒子，具有13 m长、6 m直径的超导螺线管磁铁（3.8 T）
- **LHCb探测器**：优化用于研究含b夸克的粒子的物质-反物质不对称性和稀有衰变，仪器化角度范围为10-300 mrad

### 数据分析策略

1. **触发和数据选择**：
   - LHCb：触发pT > 1.5 GeV/c的μ子
   - CMS：触发两个μ子，pT > 4(3) GeV/c（主导/次主导μ子）

2. **候选事例重建**：
   - 通过重建两个相反电荷且被识别为μ子的径迹形成B0(s)候选
   - 要求衰变顶点相对于原初顶点有位移
   - B0(s)候选的动量方向必须指向原初顶点

3. **多变量分析**：
   - 使用提升决策树（BDT）结合多个判别变量
   - 变量包括：μ子径迹质量、横向动量、衰变顶点拓扑、孤立性变量等

4. **本底抑制**：
   - 组合本底：两个随机μ子的组合
   - 半轻子本底：B0 → π−μ+ν等，其中中微子未探测到，带电π介子被误判为μ子
   - 峰值本底：强子两体衰变（如B0 → K+π−）中两个强子都被误判为μ子

### 联合拟合

- 对20个类别（CMS 12个 + LHCb 8个）同时进行无偏扩展最大似然拟合
- 分支比、碎裂分数比fd/fs和归一化道分支比作为共同参数
- 使用高斯约束处理系统不确定性

---

## 实验设计

### 数据集

- **CMS**：25 fb⁻¹积分亮度（2011年7 TeV + 2012年8 TeV）
- **LHCb**：3 fb⁻¹积分亮度
- 相当于两个实验总共产生约10¹²个B0s和B0介子

### 归一化

- 使用B+ → J/ψK+ 衰变作为归一化道
- 需要fd/fs比值来从B+产量推断B0s产量
- LHCb测量的fd/fs = 3.86 ± 0.22

## 结果与分析

### 分支比测量结果

$$B(B^0_s \rightarrow \mu^+\mu^-) = \left(2.8^{+0.7}_{-0.6}\right) \times 10^{-9}$$
$$B(B^0 \rightarrow \mu^+\mu^-) = \left(3.9^{+1.6}_{-1.4}\right) \times 10^{-10}$$

### 统计显著性

- B0s → μ+μ−：6.2σ（使用Wilks定理）
- B0 → μ+μ−：3.0σ（使用 Feldman-Cousins 方法）

### 与标准模型比较

- SB0s^SM = B(B0s → μ+μ−)/B(B0s → μ+μ−)SM = 0.76^{+0.20}_{-0.18}
- SB0^SM = B(B0 → μ+μ−)/B(B0 → μ+μ−)SM = 3.7^{+1.6}_{-1.4}
- 与标准模型的兼容性：B0s为1.2σ，B0为2.2σ

### 分支比之比

$$R = \frac{B(B^0 \rightarrow \mu^+\mu^-)}{B(B^0_s \rightarrow \mu^+\mu^-)} = 0.14^{+0.08}_{-0.06}$$

与标准模型预测R_SM = 0.0295^{+0.0028}_{-0.0025}的兼容性为2.3σ。

## 未来可能改进方向

1. **提高统计精度**：LHC在更高能量（13 TeV）运行，预期B0s和B0产量增加约一倍
2. **降低系统不确定性**：当前系统误差贡献分别为35%（B0s）和18%（B0）
3. **测量有效寿命**：B0s → μ+μ−的有效寿命对BSM物理敏感
4. **寻找CP破坏效应**：测量B0s介子-反B0s介子混合相关的CP破坏
5. **分析角度分布**：测量衰变的角度分布以寻找潜在的新物理效应
