# EMNLP_2025_OpenNER_1.0



# 泛读笔记：OpenNER 1.0

## 标题

**OpenNER 1.0: Standardized Open-Access Named Entity Recognition Datasets in 50+ Languages**

## 作者与单位

- **作者**：Chester Palen-Michel, Maxwell Pickering, Maya Kruse, Jonne Sälevä, Constantine Lignos
- **单位**：Michtom School of Computer Science, Brandeis University
- **邮箱**：{cpalenmichel,pickering,mayakruse,jonnesaleva,lignos}@brandeis.edu

## 一句话总结

OpenNER 1.0是一个标准化的开放获取命名实体识别（NER）数据集集合，包含36个语料库、涵盖52种语言，对原始数据进行了格式标准化和实体类型名称统一处理，并提供了基于多语言预训练模型和LLM的基线实验结果。

## 代码链接

https://github.com/bltlab/open-ner

---

## 背景

自1998年MUC-7会议以来的25年间，命名实体识别（NER）任务的数据集有了稳定发展。尽管CoNLL 2002-3共享任务数据集和OntoNotes是最著名的数据集，但自那以后已有数十种语料库以多种语言发布。然而，研究人员无法轻松地使用多个NER语料库进行研究，因为：

1. 缺乏中央存储库
2. 许多数据集格式不一致
3. 使用不同的分块编码（IOB、BIO等）
4. 缺乏文档说明

---

## 动机

现有NER数据集存在以下问题：
- **无中央仓库**：无法统一访问多个数据集
- **格式不统一**：各数据集使用不同的标注格式和编码方案
- **可用性差**：许多列出的NER资源数据集实际上无法直接使用
- **标注差异**：不同数据集使用不同的实体类型本体

因此，作者旨在创建第一个大规模的多语言、多本体NER数据集集合，以降低研究门槛。

---

## 相关工作

| 数据集 | 描述 |
|--------|------|
| CoNLL-02 | 西班牙语和荷兰语新闻数据，引入LOC/ORG/PER/MISC标签集 |
| OntoNotes | 大型多语言语料库，包含多种实体类型 |
| Universal NER (UNER) | 目标是以统一标注创建新数据集 |
| WikiAnn | 多语言NER基准，但为"银标准"（自动标注） |
| MultiCoNER | 从链接到维基百科文章的文本中提取，非人工标注 |

**与UNER的区别**：本文方法尽可能保留现有数据集的多样性，而不是重新创建统一标注的新数据集。

---

## 方法

### 2.1 选择标准

1. **开放获取**：必须真正可在互联网上免费访问，无需请求或签署协议
2. **人工注释**：必须使用明确标注指南手动注释，不包含"银标准"数据集
3. **通用本体**：聚焦传统命名实体（人物、地点、组织等），不包含生物医学、法律等特定领域
4. **足够数据**：必须有足够的训练和测试数据
5. **分词格式**：必须以分词格式提供，或可轻松转换为CoNLL格式

### 2.2 标准化流程

```
现有数据集 → CoNLL格式转换 → 标签转换验证与修复 → 实体类型标准化 → OpenNER
```

1. **CoNLL格式转换**：转换为BIO编码的CoNLL格式，UTF-8文本编码
2. **标签转换验证**：使用SeqScore验证BIO编码，自动修复无效标签序列
3. **实体类型标准化**：将60种不同实体类型名称统一（如PERSON、PER、PERS→PER）
4. **核心类型版本**：额外提供仅包含PER、LOC、ORG三种核心类型的版本

## 实验设计

### 模型选择

1. **微调模型**：
   - XLM-RoBERTa Base (2.79亿参数)
   - mBERT (1.79亿参数)
   - Glot500 (3.95亿参数)

2. **LLM基线**：
   - Aya-Expanse 32b
   - QwQ-32B-Preview

### 实验策略

1. **独立模型**：每个语言-数据集组合单独训练（67种组合）
2. **核心类型模型**：使用核心类型（PER、LOC、ORG）训练
3. **多语言模型**：跨所有数据集和语言训练，限制每语言每数据集最多32k句子

### 超参数

- 学习率：5.0e-5
- 训练轮数：10
- 权重衰减：0.05
- 批量大小：16
- 预热比例：0.1

### 评估指标

使用SeqScore计算微平均提及级F1分数，报告10次不同随机种子实验的平均值和标准误差。

## 结果与分析

### 完整本体结果

| 模型 | 平均F1 |
|------|--------|
| XLM-R | 81.79 |
| Glot500 | 80.96 |
| mBERT | 74.42 |

**关键发现**：
- XLM-R在完整本体上表现最佳
- Glot500在资源较少的语言上表现更好
- mBERT在中文数据集上表现显著更好
- mBERT在阿姆哈拉语上完全失效（未预训练Ge'ez文字）

### 核心类型结果

| 训练方式 | 模型 | 平均F1 |
|----------|------|--------|
| 独立 | mBERT | 75.69 |
| 独立 | XLM-R | 83.10 |
| 独立 | Glot500 | 82.10 |
| 多语言 | mBERT | 78.33 |
| 多语言 | XLM-R | 84.18 |
| 多语言 | **Glot500** | **84.89** |
| 上下文学习 | Aya-Expanse 32b | 60.55 |
| 上下文学习 | QwQ 32b Preview | 60.66 |

### 统计显著性检验

- 多语言模型：Glot500显著优于XLM-R（+0.71 F1, p < 0.05/3）
- 独立模型：XLM-R与Glot500差异不显著（p = 0.82 > 0.05/3）
- 所有模型均显著优于mBERT

### LLM结果分析

- LLM性能显著低于微调模型（F1约60 vs 80+）
- 两个LLM经常得分相同，表明上下文示例可能是限制因素
- 5-shot上下文学习优于zero-shot和JSON输出格式

### 关键洞察

1. **无万能模型**：没有单一模型在所有语言和数据集上表现最佳
2. **多语言迁移学习**：对资源较少的语言有帮助，但对高资源语言可能不如单语言模型
3. **LLM潜力**：当前LLM在NER任务上表现不佳，需要进一步研究

---

## 未来改进方向

1. **数据集扩展**：纳入更多符合条件的语料库，特别是亚洲和南美语言
2. **实体类型映射优化**：探索更好的从标准化版本到替代统一类型的映射方法
3. **多语言模型改进**：研究如何更好地处理不同标注指南之间的差异
4. **LLM研究**：探索LLM在NER中的潜力，包括合成数据生成和少样本示例检索
5. **定期更新**：随着新数据集的发布，持续更新OpenNER
6. **跨语言迁移学习**：进一步探索不同语言间的知识迁移

---

## 局限性

1. **语言覆盖不均**：非洲语言过度代表，亚洲和南美语言覆盖不足
2. **文字系统**：大部分为拉丁文字，非拉丁文字覆盖需加强
3. **标注差异**：尽管类型名称相同，但不同语料库的标注指南不同，可能导致噪声
4. **历史数据缺失**：许多旧数据集已无法获取

---

## 伦理考量

- 所有数据集均确认可重新分发
- 存在原始数据所有者可能误述数据限制的风险
- OpenNER将促进多语言NER研究，特别是关注高质量人工标注数据
