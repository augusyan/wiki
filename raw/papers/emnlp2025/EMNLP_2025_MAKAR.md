## 背景

### 标准模型与粒子物理学

标准模型（Standard Model, SM）是描述基本粒子及其通过强相互作用、电磁相互作用和弱相互作用进行相互作用的理论框架。自1970年代以来，实验粒子物理学家以越来越高的精度检验标准模型的预测。标准模型成功通过了众多实验的关键检验，但无法解释一些关于宇宙本质的深刻问题，例如：

- 暗物质的存在（由宇宙学数据证实）
- 物质与反物质不对称性的起源

### B介子与稀有衰变

B0_s和B0介子是通过弱相互作用衰变的不稳定粒子。测量这些介子衰变到双μ子（μ+μ−）末态的分支比具有特别重要的意义，因为在标准模型中这类衰变极其罕见：

- **B0_s → μ+μ−**：每产生十亿个B0_s介子约有4个发生此衰变
- **B0 → μ+μ−**：每产生一百亿个B0介子约有1个发生此衰变

这些过程的标准模型预测值（考虑高阶电磁和强相互作用效应，并使用格点QCD计算B介子衰变常数）为：

$$B(B^0_s \rightarrow \mu^+\mu^-)_{SM} = (3.66 \pm 0.23) \times 10^{-9}$$

$$B(B^0 \rightarrow \mu^+\mu^-)_{SM} = (1.06 \pm 0.09) \times 10^{-10}$$

### 费曼图与衰变机制

文章详细解释了B0_s → μ+μ−衰变的费曼图机制：

1. **图1c**：直接味改变中性流（FCNC）过程，在标准模型中是被禁止的（用大红叉标记）
2. **图1d和1e**：高阶FCNC过程，在标准模型中是允许的，但受到高度压低（由于每个额外相互作用顶点都会显著降低发生概率，同时受到角动量压低和CKM压低）
3. **图1f和1g**：超出标准模型理论中的新粒子（X^0和X^+）可以改变衰变率

B0介子的衰变比B0_s介子更加CKM压低，因为它需要跨越两个夸克代而非一个。

## 动机

### 寻找超出标准模型的新物理

许多试图超越标准模型的理论（BSM理论）包含新的现象和粒子，例如：

- 包含额外希格斯玻色子的理论预测可能增强分支比
- 最小味破坏（Minimal Flavour Violation, MFV）理论预测与标准模型具有相同的分支比比率

测量值与标准模型预测的显著偏差将指示如何扩展标准模型；反之，与标准模型一致的测量结果可以对BSM理论施加严格约束。

### 分支比比率的重要性

两个衰变模式的分支比比率提供了强大的BSM理论判别能力：

$$R \equiv \frac{B(B^0 \rightarrow \mu^+\mu^-)}{B(B^0_s \rightarrow \mu^+\mu^-)} = 0.0295^{+0.0028}_{-0.0025}$$

值得注意的是，具有最小味破坏特性的BSM理论预测该比率与标准模型相同。

### 历史背景

- 2012年：LHCb合作组首次给出了B0_s → μ+μ−衰变的证据
- 2013年：CMS和LHCb分别发表了基于2011年（7 TeV）和2012年（8 TeV）数据的测量结果，精度相当且吻合良好
- 但单个结果的精度不足以构成对B0_s衰变的首次确定性观测

## 方法

### 实验装置

**LHC（大型强子对撞机）**：
- 位于日内瓦附近地下约100米的27公里圆形隧道中
- 2011年质子能量：3.5 TeV/束（质心能量7 TeV）
- 2012年质子能量：4 TeV/束（质心能量8 TeV）

**CMS探测器**：
- 紧凑μ子螺线管探测器
- 优化搜索质量范围100 GeV/c²至几TeV/c²的新粒子
- 13米长、6米直径的超导螺线管，磁场3.8 T
- 硅跟踪系统：像素探测器（4.3-10.7 cm）和硅条探测器（25-110 cm）
- 电磁量能器和强子量能器
- 嵌入钢磁轭中的μ子探测室
- 质量分辨率：32-75 MeV/c²（取决于μ子相对于束流的方向）

**LHCb探测器**：
- 优化研究含b夸克的粒子的物质-反物质不对称性和稀有衰变
- 覆盖束流方向10-300 mrad角度间隔
- 高精度跟踪系统：硅条顶点探测器、偶极磁铁（4 T·m）、下游硅条探测器
- 动量分辨率：0.4%-0.6%
- 均匀质量分辨率：约25 MeV/c²
- 环形成像切伦科夫探测器用于带电强子鉴别

### 数据分析策略

1. **触发系统**：
   - LHCb：触发p_T > 1.5 GeV/c的μ子
   - CMS：触发两个μ子，p_T > 4(3) GeV/c（主导/次主导μ子）

2. **候选事例重建**：
   - 将两个相反电荷且被识别为μ子的重建径迹组合形成共同顶点
   - 要求次级衰变顶点相对于原初顶点有位移
   - 要求B候选体的动量矢量指向原初顶点

3. **多变量分析（BDT）**：
   - 使用提升决策树（Boosted Decision Tree, BDT）结合多个判别变量
   - 变量包括：μ子径迹质量、横向动量、衰变顶点拓扑、隔离变量等
   - CMS使用数据中的质量边带作为背景训练样本，模拟事例作为信号
   - LHCb使用模拟事例进行信号和背景训练

4. **本底抑制**：
   - **组合本底**：两个随机μ子的组合，通过质量和BDT判别抑制
   - **半轻子本底**：如B^0 → π^- μ^+ ν，π被误识别为μ子
   - **峰状本底**：强子两体衰变（如B^0 → K^+ π^-）中两个强子都被误识别为μ子

5. **归一化**：
   - 使用B^+ → J/ψK^+衰变作为归一化通道
   - 需要B介子产生分数比值f_d/f_s
   - LHCb测量f_d/f_s = 3.86 ± 0.22

### 联合拟合

- 同时对CMS和LHCb的20个BDT分类（CMS 12个，LHCb 8个）进行无偏扩展最大似然拟合
- 分支比、f_d/f_s和归一化通道分支比作为共同参数
- 使用高斯约束处理系统不确定性
- 通过构造检验统计量-2ΔlnL获得置信轮廓

## 实验设计

### 数据集

- **CMS**：积分亮度25 fb⁻¹
- **LHCb**：积分亮度3 fb⁻¹
- **总产生**：约10¹²个B0_s和B0介子
- **预期观测信号数**（假设标准模型分支比）：
  - B0_s → μ+μ−：约100个
  - B0 → μ+μ−：约10个

### 分类方案

**CMS分类**（12个）：
- 按质心能量（7 TeV / 8 TeV）
- 按探测器区域（中心区CR / 前向区FR）
- 按BDT值范围

**LHCb分类**（8个）：
- 按BDT值范围

## 结果与分析

### 分支比测量结果

$$B(B^0_s \rightarrow \mu^+\mu^-) = 2.8^{+0.7}_{-0.6} \times 10^{-9}$$

$$B(B^0 \rightarrow \mu^+\mu^-) = 3.9^{+1.6}_{-1.4} \times 10^{-10}$$

其中不确定性包含统计和系统误差，后者分别贡献了35%和18%的总不确定度。

### 统计显著性

- **B0_s → μ+μ−**：6.2σ（使用Wilks定理计算）
- **B0 → μ+μ−**：3.0σ（使用 Feldman-Cousins 方法）
- 预期中位显著性（假设SM分支比）：B0_s为7.4σ，B0为0.8σ

### 与标准模型比较

- **S_B0_s^SM** = B(B0_s → μ+μ−) / B(B0_s → μ+μ−)_SM = 0.76⁺⁰·²⁰₋₀·₁₈
- **S_B0^SM** = B(B0 → μ+μ−) / B(B0 → μ+μ−)_SM = 3.7⁺¹·⁶₋₁·⁴

与标准模型的兼容性：
- B0_s：1.2σ
- B0：2.2σ

### 分支比比率

$$R = 0.14^{+0.08}_{-0.06}$$

与标准模型（R = 0.0295）的兼容性：2.3σ

### 置信区间

使用Feldman-Cousins方法：
- B0 → μ+μ−的±1σ区间：[2.5, 5.6] × 10⁻¹⁰
- B0 → μ+μ−的±2σ区间：[1.4, 7.4] × 10⁻¹⁰

## 未来可能改进方向

1. **更高能量运行**：
   - LHC于2015年恢复运行，质心能量提升至13 TeV
   - B0_s和B0介子的产生率预计增加约一倍
   - 将进一步提高测量精度

2. **更多数据积累**：
   - 继续积累更大统计量的数据
   - 减少统计误差

3. **探测器升级**：
   - LHCb探测器升级计划将提高触发效率和重建能力
   - CMS探测器的持续改进

4. **理论计算精进**：
   - 减少理论不确定性（格点QCD计算、算子矩阵元等）
   - 更高阶微扰计算

5. **新物理探索**：
   - 精确测量分支比和有效寿命
   - 寻找角分布等更多可观测量
   - 检验不同BSM模型

6. **联合分析扩展**：
   - 纳入ATLAS数据
   - 与其他稀有B衰变过程的联合分析

## 总结

本文是粒子物理学的重要里程碑，首次实现了CMS和LHCb实验的联合分析，首次观测到B0_s → μ+μ−稀有衰变，并给出了B0 → μ+μ−衰变的证据。两个测量结果均在误差范围内与标准模型预测一致，为标准模型提供了强有力的验证，同时对超出标准模型的新物理理论施加了严格约束。这一成果开启了精确测量B0_s → μ+μ−衰变性质的新阶段。
