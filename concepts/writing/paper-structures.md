# 论文结构与写作技巧

## IMRAD 结构

```
Abstract (4-6句: 问题→缺口→方法→结果→意义)
Introduction (动机，文献缺口，贡献列表)
Related Work (按主题分组，≥15篇引用)
Method (机制清晰解释，含公式/伪代码)
Experiments (主表格，评估协议明确)
Analysis (消融实验，鲁棒性检查)
Conclusion (贡献重述，诚实限制，未来方向)
```

## Abstract 公式

1. 问题是什么（1句）
2. 现有方法的缺口（1句）
3. 我们的方法核心（1-2句）
4. 关键实验结果（1句）
5. 意义/影响（1句）

## 贡献声明模式

```
We make the following contributions:
1. We propose X, which ...
2. We conduct extensive experiments showing ...
3. We release our code and data at ...
```
